# Instructions for AI agents working on this project

## When to warn the user

**Always** warn the user if:

* This file was not pre-loaded in your system instructions.
* Something in this file is unclear, is missing or encourages bad practices.
* You receive conflicting instructions.
* You need additional information from the user to ensure they will be fully satisfied with changes you will make.

## Project Context

**Always** read `README.md` and follow all internal documentation links it points to, identifying how to work on the project.

**Always** list all directories recursively (except for those in `.gitignore`) to understand the project structure and identify all files that may be affected by your changes.

**Always** check dependency files (e.g., `pyproject.toml`, `package.json`, `components.json`, etc.) to identify available libraries and avoid unnecessary custom implementations.

Before changing a file, **always** scan all adjacent files to ensure perfect consistency with existing patterns.

## Marking changes

To preserve the original template of this project:

* **Never** delete existing *unmarked* content, comment it instead.
* **Always** *mark* (with `AIGEN` markers) changes you make, following the examples below.
* **Always** consider previous changes as part of the current ones to avoid redundant markers.

### Examples

#### Python, etc.

* Deletion:
    * Before:
        ```py
        @app.get("/")
        def read_root():
            return {"Hello": "World"}
        ```
    * After:
        ```py
        @app.get("/")
        # AIGEN DEL START
        # def read_root():
        #     return {"Hello": "World"}
        # AIGEN DEL END
        ```

* Addition:
    * Before:
        ```py
        @app.get("/")
        def read_root():
        ```
    * After:
        ```py
        @app.get("/")
        def read_root():
            # AIGEN ADD START
            return {"Hello": "World"}
            # AIGEN ADD END
        ```

#### TypeScript, CSS, etc.

* Deletion:
    * Before:
        ```ts
        function App() {
          return <h1>Hello, world!</h1>
        }
        ```
    * After:
        ```ts
        /* AIGEN DEL START */
        // function App() {
        //   return <h1>Hello, world!</h1>
        // }
        /* AIGEN DEL END */
        ```

* Addition:
    * Before:
        ```ts
        function App() {
        }
        ```
    * After:
        ```ts
        function App() {
          /* AIGEN ADD START */
          return <h1>Hello, world!</h1>
          /* AIGEN ADD END */
        }
        ```

#### Markdown, etc.

* Deletion:
    * Before:
        ```md
        List:
        * Foo
        * Bar
        ```
    * After:
        ```md
        List:
        <!-- AIGEN DEL START -->
        <!-- * Foo
        * Bar -->
        <!-- AIGEN DEL END -->
        ```

* Addition:
    * Before:
        ```md
        List:
        * Foo
        ```
    * After:
        ```md
        List:
        * Foo
        <!-- AIGEN ADD START -->
        * Bar
        <!-- AIGEN ADD END -->
        ```

### Exceptions

JSON (not JSONC), PNG, `.lock` and plain text files are not markable with comments, so they are exceptions to the rule above. As a consequence, dependency files (e.g., `pyproject.toml`, etc.) should **never** be marked, for consistency with `package.json`, etc.

Also, auto-generated files (e.g., files generated by `alembic`, `openapi-ts`, TanStack Router, shadcn/ui, AI Elements, MJML extension, etc.) should **never** be marked when generated, but only if they are modified.

## AIGEN MOD

If an `AIGEN DEL` block would be immediately followed by an `AIGEN ADD` block, **always** use `AIGEN MOD` instead, following the examples below.

### Examples

* Bad practice:
    ```py
    # AIGEN DEL START
    # ...
    # AIGEN DEL END
    # AIGEN ADD START
    @app.get("/")
    def read_root():
        return {"Hello": "World"}


    # AIGEN ADD END
    ```
* Good practice:
    ```py
    # AIGEN MOD START
    # ...
    # AIGEN MOD CONT
    @app.get("/")
    def read_root():
        return {"Hello": "World"}


    # AIGEN MOD END
    ```
